# CLAN — Climate Leaders Action Network Website

Static, responsive multi-page website prototype.

## Files
- `index.html` — Home
- `about.html` — About
- `work.html` — What we're working on
- `network.html` — Members / Network
- `join.html` — Join CLAN
- `stories.html` — News / Blog
- `gallery.html` — Gallery / Media
- `contact.html` — Contact
- `assets/style.css` — Design system and responsive styling
- `assets/script.js` — Mobile navigation

## Run locally
Open `index.html` in a browser.

## Publish
This can be uploaded directly to GitHub Pages, Cloudflare Pages, Netlify, or similar static hosting.

## Before launch
Replace placeholder gallery/story blocks with real photos and articles, add official social links, and connect the contact/join forms to your chosen form/email service.
